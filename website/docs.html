Getting started / Quickstart

Quickstart

Get your context syncing across every device, editor, and agent in under two minutes.

Install

Install the asp CLI with a single command. It runs anywhere — macOS, Linux, or WSL.
$ curl -fsSL get.asp.dev | sh
# installs asp 1.0.0 to /usr/local/bin

Initialize a context

Run asp init inside any folder of notes or markdown to start tracking it.
$ cd ~/notes
$ asp init
✓ created .asp/ · tracking 0 files
◆
Already using Git?
asp init detects your repository and syncs alongside it — no migration, no lock-in.

Sync everywhere

Add a remote and start the watcher. Every change is versioned and mirrored to your other devices and agents in real time.
$ asp remote add origin asp://you@cloud
$ asp sync --watch
↻ watching ~/notes · 3 devices · 0 conflicts
